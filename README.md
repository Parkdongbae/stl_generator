# STL Generator

OpenSCAD `.scad` 파일에서 부재(部材)를 자동 인식해 체크박스로 선택하고, 선택한 부재를 **하나의 STL로 병합**하거나 **부재별 개별 STL**로 내보내는 로컬 웹앱입니다.

- **단일 파일**: 서버 + HTML/CSS/JS를 `StlGenerator.java` 한 파일에 내장 (외부 라이브러리 0개, JDK 내장 HttpServer)
- **부재 자동 감지**: `PART`/`IDX` 플래그 방식 파일 또는 일반 `module` 방식 파일 자동 판별
- **병합 내보내기**: 여러 부재 → 바이너리 STL 정밀 병합 (삼각형 수 검증)
- **개별 내보내기 / IDX 자동 열거**: 부재별 분리, 개별 번호(IDX 0~N-1) 일괄 분리
- **3D 미리보기**: WebGL 직접 구현(외부 라이브러리 없음), 삼각형 수/실제 크기(mm) 표시
- **비동기 작업 큐**: 진행률 바 · 작업 취소
- **크기 비율 일괄 조정**: 예) 0.5=절반, 2=두 배
- **편의 기능**: 파일 선택 대화상자, 드래그&드롭, 폴더 브라우저, 최근 파일/폴더 기억

## 요구사항

- JDK 17 이상
- [OpenSCAD](https://openscad.org/) — 표준 설치 경로(`Program Files`) 또는 `PATH`에서 자동 감지

## 실행

```bat
javac -encoding UTF-8 StlGenerator.java
java StlGenerator
```

또는 Windows에서 `실행.bat` 더블클릭(컴파일되어 있지 않으면 자동 컴파일). 브라우저가 `http://localhost:8765`로 자동 열립니다.

## 사용 순서

1. SCAD 파일 불러오기 (경로 입력 / 파일 선택 / 드래그&드롭)
2. 내보낼 부재 체크 (PART 모드는 행별 IDX 지정 가능, 빈칸 = 종류 전체)
3. 병합 / 개별 모드 선택, 크기 비율 입력, 저장 폴더 지정
4. STL 내보내기 → 진행률 확인 → 결과 행의 `3D` 버튼으로 미리보기
